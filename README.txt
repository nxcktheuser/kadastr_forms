Кадастровые формы — офлайн-приложение.
Разместите содержимое этой папки на любом HTTPS-хостинге (Netlify Drop, GitHub Pages и т.п.).
Откройте ссылку один раз с интернетом — дальше приложение работает и без сети.
На телефоне: меню браузера → «Установить приложение» / «На экран Домой».
Проекты хранятся на устройстве. Перенос между устройствами — кнопки «Сохранить проекты в файл» / «Загрузить из файла».
